SquaredJointAngleCost¶

Bases: ssqp::model::stagewise::predefined::costs::PredefinedStageCost

#include <model/stagewise/predefined/Costs.hpp>

Predefined squared joint angle cost.

Defines the cost term \(\ell(\boldsymbol{x}, \boldsymbol{u}) = \frac{1}{2} \lVert \boldsymbol{w} \odot \boldsymbol{x}_{ang} \rVert_2^2\)

where:

  • \(\boldsymbol{x}_{ang}\) is the angular (position) part of the state Note that this will ignore the first 7 elements if the model has a floating base
  • \(\boldsymbol{w}\) is the weight on the angular term

Assumes:

  • The model joint configuration is the first part of the state vector (size model.nq()), appearing after the floating base (if present)

SquaredIDTorqueCost¶

Bases: ssqp::model::stagewise::predefined::costs::PredefinedStageCost

#include <model/stagewise/predefined/Costs.hpp>

Predefined squared inverse dynamics torque cost.

Defines the cost term \(\ell(\boldsymbol{x}, \boldsymbol{u}) = \frac{1}{2} \lVert \boldsymbol{w} \odot \boldsymbol{\tau} \rVert_2^2\) where:

  • \(\boldsymbol{\tau}\) is the actuated-joint torque caused by the controls (see Model::getActuatedTorqueVector)
  • \(\boldsymbol{w}\) is the weight on the torque term

Note that this cost assumes inverse dynamics is being used (i.e. treats controls as accelerations)

Assumes:

  • The model is in Inverse Dynamics or Reduced Inverse Dynamics mode, such that the state is made up of configuration and velocity and the controls are made up of accelerations (including base, for Inverse Dynamics; actuated joints only, for Reduced Inverse Dynamics) and potential forces

The torque accounts for the forces of the stage the cost is added to, which the model passes in when it's finalized. A single instance can only be added to several stages if they all have the same forces, so construct one instance per stage otherwise

FloatingBaseSquaredTranslationErrorCost¶

Bases: ssqp::model::stagewise::predefined::costs::PredefinedStageCost

#include <model/stagewise/predefined/Costs.hpp>

Predefined squared floating base translation error cost.

Defines the cost term \(\ell(\boldsymbol{x}, \boldsymbol{u}) = \frac{1}{2} \lVert \boldsymbol{w} \odot R^\top (\boldsymbol{t}_f - \boldsymbol{t}_d)\rVert_2^2\)

where:

  • \(\boldsymbol{t}_f\) is the floating base translation (in \(\mathcal{R}^3\))
  • \(\boldsymbol{t}_d\) is the desired translation of the floating base (in \(\mathcal{R}^3\))
  • \(\boldsymbol{w}\) is the weight on the translation error
  • \(R\) is the rotation of the reference frame the error is expressed in (World, Fixed, Local or Base, identity for World, with Local and Base both the base's axes)

Assumes:

  • The model joint configuration is the first part of the state vector (size model.nq())
  • The floating base translation is extracted from the base pose of the model state representation

FloatingBaseSquaredPoseErrorCost¶

Bases: ssqp::model::stagewise::predefined::costs::PredefinedStageCost

#include <model/stagewise/predefined/Costs.hpp>

Predefined squared floating base pose error cost.

Defines the cost term \(\ell(\boldsymbol{x}, \boldsymbol{u}) = \frac{1}{2} D^\top W D\)

where:

  • \(D = \log_{SE(3)} T^{-1}T_d\)
  • \(T\) is the floating base pose (in \(\mathit{SE3}\))
  • \(T_d\) is the desired floating base pose (in \(\mathit{SE3}\))
  • \(W\) is a weight matrix, made up of parameters \(w_p\) for translation and \(w_r\) for rotation

Assumes:

  • The model joint configuration is the first part of the state vector (size model.nq())

Bases: ssqp::model::stagewise::predefined::costs::PredefinedStageCost

#include <model/stagewise/predefined/Costs.hpp>

Predefined squared frame terrain height error cost.

Defines the cost term \(\ell(\boldsymbol{x}, \boldsymbol{u}) = \frac{1}{2} w^2 (p_z - h(p_x, p_y) - d_d)^2\)

where:

  • \(\boldsymbol{p}\) is the frame translation for a given frame of the model (in \(\mathcal{R}^3\))
  • \(h\) is the height of the terrain at the frame's horizontal position, the model's terrain unless the cost is given one of its own
  • \(d_d\) is the desired height of the frame above the terrain
  • \(w\) is the weight on the height error

Assumes:

  • The model joint configuration is the first part of the state vector (size model.nq())

  • \(T_d\) is the desired pose for that frame (in \(\mathit{SE3}\))
  • \(W\) is a weight matrix, made up of parameters \(w_p\) for translation and \(w_r\) for rotation

Assumes:

  • The model joint configuration is the first part of the state vector (size model.nq())

  • \(\boldsymbol{v}_d\) is the desired velocity for that frame (in \(\mathcal{R}^6\)), expressed in the same reference frame
  • \(\boldsymbol{w}\) is the weight on the velocity error

Assumes:

  • The model joint configuration is the first part of the state vector (size model.nq())
  • The model joint velocity is the final part of the state vector (size model.nv())

FramesInverseSquaredDistanceCost¶

Bases: ssqp::model::stagewise::predefined::costs::PredefinedStageCost

#include <model/stagewise/predefined/Costs.hpp>

Predefined frames squared inverse distance cost.

Defines the cost term \(\ell(\boldsymbol{x}, \boldsymbol{u}) = \sum_{i < j} \frac{w}{2 \lVert \boldsymbol{\sigma} \odot R^\top (\boldsymbol{t}_i - \boldsymbol{t}_j)\rVert_2^2}\)

where:

  • \(\boldsymbol{t}_i\) is the frame translation for frame \(i\) of the model (in \(\mathcal{R}^3\))
  • \(w\) is the weight on the translation error
  • \(\boldsymbol{\sigma}\) is the distance scale, a per-axis vector (in \(\mathcal{R}^3\)) determining the scaling factor for each axis; the factors work in an inverse manner, i.e. larger values place less importance on an axis, while smaller ones place more
  • \(R\) is the rotation of the reference frame whose axes the distance scale applies along (World, Fixed or Base, identity for World)

Assumes:

  • The model joint configuration is the first part of the state vector (size model.nq())

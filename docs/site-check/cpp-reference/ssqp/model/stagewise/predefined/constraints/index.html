JointAngleConstraint¶

Bases: ssqp::model::stagewise::predefined::constraints::PredefinedStageConstraints

#include <model/stagewise/predefined/Constraints.hpp>

Predefined joint angle constraint.

Creates a constraint on the joint angles of the model

Note: this constraint is separate to any potential innate constraints \(\boldsymbol{q}_l \leq \boldsymbol{q} \leq \boldsymbol{q}_u\)

where:

  • \(\boldsymbol{q}_l\), \(\boldsymbol{q}_u\): Lower and upper configuration vectors
  • \(\boldsymbol{q}\): The model's joint configuration vector

Assumes:

  • The model joint configuration is the first part of the state vector (size model.nq()), appearing after the floating base (if present)

FloatingBaseTranslationBound¶

Bases: ssqp::model::stagewise::predefined::constraints::PredefinedStageConstraints

#include <model/stagewise/predefined/Constraints.hpp>

Floating base position bound constraint.

Creates a linear bound constraint on the position of the floating base: \(\boldsymbol{b}_l \leq R^\top (p_f - \boldsymbol{c}) \leq \boldsymbol{b}_u\)

where:

  • \(\boldsymbol{b}_l\), \(\boldsymbol{b}_u\): Lower and upper bound vectors on the base position (in \(\mathcal{R}^3\))
  • \(p_f\): Floating base position extracted from the system state
  • \(R\): Rotation of the reference frame the bounds are expressed in (World, Fixed, Local or Base, identity for World, with Local and Base both the base's axes)
  • \(\boldsymbol{c}\): Center the bounds are taken around (in \(\mathcal{R}^3\))

Assumes:

  • The Model contains a floating-base where the base position is the first part of the configuration vector (first 3 elements of size model.nq())

FloatingBaseRotationBound¶

Bases: ssqp::model::stagewise::predefined::constraints::PredefinedStageConstraints

#include <model/stagewise/predefined/Constraints.hpp>

Predefined floating base orientation bound.

Creates a nonlinear bound constraint on the orientation of the floating base: \(\boldsymbol{b}_l \leq \log_{SO3}(R_{ref}^\top R_f) \leq \boldsymbol{b}_u\)

where:

  • \(\boldsymbol{b}_l\), \(\boldsymbol{b}_u\): Lower and upper bound vectors on the orientation error (in \(\mathcal{R}^3\))
  • \(R_f\): Floating base rotation matrix
  • \(R_{ref}\): Reference rotation matrix

Assumes:

  • The model joint configuration is the first part of the state vector (size model.nq())
  • The floating base orientation is represented as a rotation matrix in SE(3) and can be extracted from the base pose in the system state

#include <model/stagewise/predefined/Constraints.hpp>

Predefined floating base SE(3) pose bound.

Creates a nonlinear bound constraint on the full pose (position + orientation) of the floating base: \(\boldsymbol{b}_l \leq \log_{SE3}(T_{ref}^{-1} T_f) \leq \boldsymbol{b}_u\)

where:

  • \(\boldsymbol{b}_l\), \(\boldsymbol{b}_u\): Lower and upper bound vectors on the pose error (in \(\mathcal{R}^6\))
  • \(T_f\): Floating base pose in SE(3)
  • \(T_{ref}\): Reference pose in SE(3)

Assumes:

  • The model joint configuration is the first part of the state vector (size model.nq())
  • The floating base pose is represented as an SE(3) transform and can be extracted from the base state in the system model

Predefined center of mass bound.

Creates a linear bound constraint on the center of mass of the model: \(\boldsymbol{b}_l \leq R^\top (\boldsymbol{c} - \boldsymbol{c}_0) \leq \boldsymbol{b}_u\)

where:

  • \(\boldsymbol{b}_l\), \(\boldsymbol{b}_u\): Lower and upper bound vectors (in \(\mathcal{R}^3\))
  • \(\boldsymbol{c}\) is the center of mass of the model
  • \(R\): Rotation of the reference frame the bounds are expressed in (World, Fixed or Base, identity for World)
  • \(\boldsymbol{c}_0\): Center the bounds are taken around (in \(\mathcal{R}^3\))

Assumes:

  • The model joint configuration is the first part of the state vector (size model.nq())

ContactConstraint¶

Bases: ssqp::model::stagewise::predefined::constraints::PredefinedStageConstraints

#include <model/stagewise/predefined/Constraints.hpp>

Predefined contact constraint for a given frame Creates a set of constraints that amount to a contact force constraint for a frame This consists of the following 4-point linearized friction cone constraints:

  • \(f_n \gt 0\)
  • \(|f_1| \leq \mu f_n\)
  • \(|f_2| \leq \mu f_n\) As well as the following constraint on the 3D position of the frame the contact is on:
  • \(p_z = h_z\) And, unless no_slip is false, the following no-slip constraint on the linear velocity of the frame:
  • \(\boldsymbol{v}_f = \boldsymbol{0}\) where:
  • \(f_n\) is the normal of the contact force ( \(f_z\))
  • \(f_1\) is the first component of the tangential contact force ( \(f_x\))
  • \(f_2\) is the second component of the tangential contact force ( \(f_y\))
  • \(\mu\) is the static friction coefficient at the contact
  • \(p_z\) is the \(z-\)component of the translation of the frame the contact is on
  • \(h_z\) is the height of the terrain at point \((p_x, p_y)\)
  • \(\boldsymbol{v}_f\) is the linear velocity of the frame the contact is on Note that when manually adding this contact constraint to a model, an external force must be added to the model and the appropriate methods must be called to correctly assign that force to this constraint. To avoid this, simply use the Model's addConstraints function, instantiated with the template type ContactConstraint. In that case, adding and assigning of the force will be handled automatically.

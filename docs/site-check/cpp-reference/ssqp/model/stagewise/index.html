state_right_plus virtual¶

virtual void state_right_plus(ConstVecXRef x, ConstVecXRef dx, VecX &out) const

Operator definitions for states Defines operators between states and state differences If state is a euclidian vector, these operators reduce to simple addition/subtraction If state is a lie group element, these operators perform conversions between elements of the group (manifold) and tangent space elements The state can also be composite, i.e made up of one or more manifolds and one or more euclidian vectors, in which case operators act segment-wise.

Defines right plus operator between state vector and tangent space vector Inputs: State vector \(\boldsymbol{x}\) (size \(n_x\)), state difference vector \(\boldsymbol{dx}\) (size \(n_{dx}\)) Output: State \(\boldsymbol{y}\) (size \(n_x\)) Default behavior: \(\boldsymbol{x} + \boldsymbol{dx}\)

state_right_minus virtual¶

virtual void state_right_minus(ConstVecXRef x, ConstVecXRef y, VecX &out) const

Defines right minus operator between states Inputs: Composite states \(\boldsymbol{x}\), \(\boldsymbol{y}\) (vectors/lie group elements, size \(n_x\)) Output: State difference vector \(\boldsymbol{dx}\) (size \(n_{dx}\)) Default behavior: \(\boldsymbol{x} - \boldsymbol{y}\).

gradient pure-virtual¶

virtual void gradient(ConstVecXRef x, ConstVecXRef u, MatX &dX, MatX &dU) const = 0

Get dynamics Jacobians with respect to \(\boldsymbol{x}\) and \(\boldsymbol{u}\), evaluated at given \((\boldsymbol{x}, \boldsymbol{u})\): \(\nabla_x \boldsymbol{f}_k(\boldsymbol{x}, \boldsymbol{u})\) and \(\nabla_u \boldsymbol{f}_k(\boldsymbol{x}, \boldsymbol{u})\) Returns: dX: gradient with respect to \(\boldsymbol{x}\), \(n_{dx} \times n_{dx}\) dU: gradient with respect to \(\boldsymbol{u}\), \(n_{dx} \times n_u\).

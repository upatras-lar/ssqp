MPC¶

#include <solvers/mpc.hpp>

MPC class Helper class which utilizes SSQP to perform MPC for real-time SSQP-based control.

Repeatedly uses SSQP with low iterations to solve a problem for the current state of a system, applies the first of the generated controls, updates the initial guess using feedback from the system and a warm start using the previous solution and repeats the process.

ssqp¶

#include <solvers/ssqp.hpp>

SSQP class Defines an SSQP problem solver based on a given SSQP model and the desired parameters.

SSQP is a Structure-exploiting Sequential Quadratic Programming solver. The solver starts with an initial guess (either provided, or zero) for the states (x) and controls (u) of an optimization problem over a time horizon H.

At each step, SSQP constructs a Quadratic Program at the current SSQP guess with a quadratic cost function and linearized constraints. This is done using the SSQP model, a model of the system being optimized which provides the necessary methods to linearize at each guess, like gradients and hessians.

The solver then utilizes a QP solver to produce a solution to the constructed QP, which can act as an update step for the current SSQP guess. Based on this solution, a line search method is used to update the current guess.

Termination criteria are then checked for the new SSQP guess. The process is repeated until convergence is reached.

QPData¶

#include <types.hpp>

Defines a QP of the following form, to be solved using ADMM.

\[ \Large \begin{equation} \begin{split} &\min_{\boldsymbol{x}, \boldsymbol{u}} \sum_{k=0}^{H-1} ( \frac{1}{2} \Bigl[\begin{smallmatrix}\boldsymbol{x}_k \\ \boldsymbol{u}_k\end{smallmatrix}\Bigr]^\top \Bigl[\begin{smallmatrix}Q_{xx} \ Q_{xu} \\ Q_{ux} \ Q_{uu}\end{smallmatrix}\Bigr] \Bigl[\begin{smallmatrix}\boldsymbol{x}_k \\ \boldsymbol{u}_k\end{smallmatrix}\Bigr] + \Bigl[\begin{smallmatrix}\boldsymbol{q}_k \\ \boldsymbol{r}_k\end{smallmatrix}\Bigr]^\top \Bigl[\begin{smallmatrix}\boldsymbol{x}_k \\ \boldsymbol{u}_k\end{smallmatrix}\Bigr] ) + \frac{1}{2}\boldsymbol{x}_H^\top Q_H \boldsymbol{x}_H + \boldsymbol{x}_H^\top q_H \\ &+ \sum_{k=0}^{H-1} ( \frac{\rho}{2} \norm{D_k \boldsymbol{x}_k + E_k \boldsymbol{u}_k - \boldsymbol{z}_k^j + \rho^{-1} \boldsymbol{y}_k^j}_2^2 ) + \frac{\rho}{2} \norm{D_H \boldsymbol{x}_H - \boldsymbol{z}_H^j + \rho^{-1} \boldsymbol{y}_H^j}_2^2 \\ &+ \sum_{k=0}^{H} ( \frac{\sigma}{2} \norm{\boldsymbol{x}_k - \boldsymbol{x}_k^j}_2^2 ) + \sum_{k=0}^{H-1} ( \frac{\sigma}{2} \norm{\boldsymbol{u}_k - \boldsymbol{u}_k^j}_2^2 ) \\ &\text{s.t.} \boldsymbol{x}_{k+1} = A_k \boldsymbol{x}_k + B_k \boldsymbol{u}_k + \gamma_k \end{split} \end{equation} \]

Terms with (^j) are constant parts of the current ADMM guess

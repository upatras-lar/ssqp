# SSQP examples
This directory contains all existing examples for the SSQP library. These examples include robotics-related OCPs for trajectory generation, as well as MPC on simulators and real systems.

Specifically:

* `trajgen` is the directory containing trajectory generation examples. These examples use SSQP to fully generate trajectories offline from scratch, often by providing relevant costs and constraints, as well as next to no additional initialization.
* `mpc` is the directory containing MPC examples for simulations. These simulations use [MuJoCo](https://mujoco.org/) as the simulator and SSQP as the controller. The simulator acts as the real system, providing feedback regarding the current state, while SSQP uses that feedback to generate and solve OCPs that determine the system controls for the next step.
* `real-mpc` is the directory containing MPC examples for real systems. This works similarly to `mpc`, but here, instead of a simulator, we use a real world system (i.e. a robot) to get state information and apply our generated controls.
* `benchmarks` is a directory for experiments to benchmark and compare various aspects of our solver, such as the performance of the forward and inverse dynamics formulations for OCPs.
* `visualizer` is the directory containing the `visualize` script, which uses [viser](https://viser.studio/main/) to visualize trajectories generated by our solver (and written to an output JSON file using the provided `solver.write` method).

### Running the Python examples
Note that, to execute the Python examples, the generated Python library for SSQP must be available to Python upon execution. This can be done by adding the directory where the `.so` file for the library exists to `PYTHONPATH`:

```
export PYTHONPATH="/path/to/so-file/ssqpy.cpython-312-x86_64-linux-gnu.so"
```

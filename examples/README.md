# SSQP examples
This directory contains all existing examples for the SSQP library. These examples include robotics-related OCPs for trajectory generation, as well as MPC on simulators and real systems.

Specifically:

* `trajgen` is the directory containing trajectory generation examples. These examples use SSQP to fully generate trajectories offline from scratch, often by providing relevant costs and constraints, as well as next to no additional initialization.
* `mujoco_mpc` is the directory containing MPC examples for simulations. These simulations use [MuJoCo](https://mujoco.org/) as the simulator and SSQP as the controller. The simulator acts as the real system, providing feedback regarding the current state, while SSQP uses that feedback to generate and solve OCPs that determine the system controls for the next step.
* `real_mpc` is the directory containing MPC examples for real systems. This works similarly to `mpc`, but here, instead of a simulator, we use a real world system (i.e. a robot) to get state information and apply our generated controls.
* `benchmarks` is a directory for experiments to benchmark and compare various aspects of our solver, such as the performance of the forward and inverse dynamics formulations for OCPs.
* `visualizer` is the directory containing the `visualize` script, which uses [viser](https://viser.studio/main/) to visualize trajectories generated by our solver (and written to an output JSON file using the provided `solver.write` method).
* `models` includes custom SSQP models that may be used in place of XML files, as well as utilities related to those models.
* `assets` includes assets such as URDF and MJCF files.

### Running the Python examples
Note that, to execute the Python examples, the generated Python library for SSQP must be available to Python upon execution.

Once the Python extension has been built, source the `setup_env.sh` script, located in this directory:

```
source setup_env.sh
```

You can now execute any of the examples from their directory via:

```
python example.py
```
